- **logo.png** → логотип (оставить logo.png)
- **Фото** (HEIC конвертировать в JPG, затем переименовать в 1.jpg–4.jpg):
  - Вид с верху.HEIC → 1.jpg (конвертировать!)
  - Макет станции.jpg → 2.jpg
  - Станция вид с угла.HEIC → 3.jpg (конвертировать!)
  - Станция.JPG → 4.jpg

Примечание: браузеры не поддерживают HEIC — конвертируйте в JPG перед добавлением.
