# Папки Enjoy Barware и Steelbar не появились?

## Причина

Проект использует **статический экспорт** (`output: 'export'`). Сайт раздаётся из папки `out`, которая создаётся при сборке. Если в `out` лежит старая сборка — будут отображаться старые данные (только Cocktail Design).

## Решение

### 1. Полная пересборка

В корне проекта выполните:

```bash
npm run rebuild
```

Или по шагам:

```bash
# Удалить кэш и старую сборку
npx rimraf .next out

# Собрать заново
npm run build
```

### 2. Проверка локально

```bash
npm start
```

Откройте http://localhost:8080/friends/, зайдите в папку «Друзья» — должны быть 3 подпапки.

### 3. Деплой

- **Timeweb / хостинг с автобилдом**: после `git push` платформа сама выполнит сборку. Убедитесь, что билд прошёл успешно.
- **Ручной деплой**: залейте содержимое папки `out` на сервер (после `npm run build`).

### 4. Очистка кэша браузера

Сделайте жёсткое обновление страницы: **Ctrl+Shift+R** (или Cmd+Shift+R на Mac).
